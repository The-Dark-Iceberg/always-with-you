## 0.2.0

**更快的聊天 / Faster chat**
- 程序先把记忆读好再交给 AI，AI 不用再自己多想一步去读：Antigravity 每句话从走三步变成走一步。
  Memories are read by the app and handed to the AI up front, so Antigravity answers in one step instead of three.
- Antigravity 默认改用 Gemini Flash (Low)，「由谁来回答」卡片上可以换档位。
  Antigravity now defaults to Gemini Flash (Low); the model can be changed on its card in *Who answers*.
- 打开「陪我聊聊」时在后台提前启动 Antigravity。
  Antigravity is started in the background when you open *Talk with me*.
- DeepSeek 边生成边显示；等待时显示已等了几秒。
  DeepSeek replies appear as they're written; while waiting you see how many seconds have passed.

**更懂你 / Knows you better**
- 聊天内容参与整理，你说的话权重最高，AI 的话只记「聊过什么」或你认同的。
  Chats are organized into memory; your own words weigh most, the AI's only count as "what we talked about" or when you agree.
- 新采集：正在播放（歌、视频）、最近打开的文件、浏览器扩展（https 网页、搜索词）。
  New sources: now playing, recently opened files, and a browser extension (https pages, search terms).
- 可设置「我所在的地区」（时区）。
  Set "My region" (time zone).

**其他 / Other**
- 新图标；托盘右键菜单换成手绘风格。
  New app icon; the tray right-click menu is now hand-drawn style.
- 聊天记录只显示最近 30 条，往上滑加载更早的；按日期分隔。
  Chat shows the latest 30 messages and loads earlier ones as you scroll up, with date dividers.
- 记忆、写入日志可按分类筛选，可导出 TXT。
  Memory and Write log can be filtered by category and exported as TXT.
- 新增「设置 → 关于与更新 → 检查更新」。
  New: *Settings → About & updates → Check for updates*.
- 中英双语界面（左下角地球图标）。
  English / Simplified Chinese interface (globe icon at the bottom left).
- 「由谁来回答」页可以一键安装 Antigravity / Claude Code / Codex 命令行。
  One-click install for the Antigravity / Claude Code / Codex CLIs on *Who answers*.
- 隐私：无标签的密码、随机密钥也会被隐藏。
  Privacy: unlabeled passwords and random-looking keys are now hidden too.
