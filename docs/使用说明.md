# 一个时刻陪着你的AI · 使用说明

> 版本 0.1.0。这份说明写给使用这个软件的人，不需要懂编程。

---

## 一、它是什么

一个只在你自己电脑上运行的「记忆 + 陪伴」小程序：

1. **安静地记录**：每隔几秒看一眼你电脑上最前面的窗口是哪个（只看软件名和窗口标题），记下你在电脑上做了什么、什么时候离开了。
2. **过滤隐私**：记录之前先过一遍隐私过滤，密码、账号、手机号、证件号、银行卡、各种密钥会被换成「[已隐藏]」；你设置的软件和关键词整条不记。
3. **每天几次整理成记忆**：到点后，把这段时间的活动写成一页摘要，交给 AI 整理成「关于你的记忆」。
4. **陪你聊天**：在「陪我聊聊」里说话时，AI 会先看一眼你的记忆，所以它知道你是谁、最近怎么样、今天在忙什么。

**它不做的事**：不录音、不截屏、不记录你按了哪些键、不读通知、不使用无障碍权限、不把原始记录上传到任何地方。

## 二、安装与卸载

### 安装
1. 双击 `AlwaysWithYou-Setup-0.3.0.exe`（版本号可能更新）。
2. 按提示点「下一步」。可以选择「创建桌面快捷方式」和「开机时自动启动」。
3. 不需要管理员权限，程序装在你自己的用户目录里。

> 杀毒软件可能会提示「未知程序」：这个软件没有花钱买数字签名，不是病毒。如果被拦，选择「仍要运行」或加入信任列表。

### 卸载
「设置 → 应用 → 已安装的应用」里找到「一个时刻陪着你的AI」，点「卸载」。
卸载时会**问你要不要同时删除记忆数据**：
- 选「否」（默认）：只删程序，记忆留着，以后重新安装可以接着用。
- 选「是」：连记忆、聊天记录、设置、记忆存档一起删除，**无法恢复**。
- 如果你把记忆库搬到过别的盘，弹窗里会把那个位置也列出来，选「是」时一起删。

## 三、第一次使用（5 分钟）

打开后，右下角托盘里会出现图标，同时弹出主窗口。

**第一页是「风险确认」**：写着它会记录什么、数据会发给谁、出了问题与作者无关等 5 条。
- 点「**我了解风险并接受使用**」才会开始记录（在这之前一条都不记）。
- 点「**退出软件**」就直接退出，下次打开还会先看到这一页。

**接着是 7 步引导**：欢迎和语言 → 我所在的地区 → 记什么、不记什么 → 由谁来回答 → 可选功能 → 你的记忆库 → 完成。
每页下面有「上一步」「下一步」，左下角「跳过所有」可以直接跳过；以后在「设置 → 其他 → 重新打开引导」还能再看。

> **重要：改了设置一定要点「保存」**（引导里是「保存设置」，有箭头指着）。它不会自动保存。
> 改了没保存时，保存按钮会一直闪着提醒你；没保存就想离开，会弹窗问你「保存 / 不保存 / 留在这里」。

引导里的内容，也可以以后在各个页面里慢慢设置：

1. **填 DeepSeek API Key**（推荐）
   「设置 → 整理记忆 → DeepSeek API Key」，填好后点最下面的「保存」。
   Key 用 Windows 自带的加密功能锁在本机，换电脑或换 Windows 账号都读不出来。
   没有 Key 的话：记录照常进行，但不会整理成记忆。

2. **选「由谁来回答」**
   左边栏「由谁来回答」页：
   - **DeepSeek API**：最快、最便宜，填了 Key 就能用。
   - **Google Antigravity**：用你的 Gemini 订阅额度。需要先安装 Antigravity 命令行并登录过（见第六节）。
   点卡片上的「聊天用它」即可切换。
   **速度**：DeepSeek 一句话大约 3~5 秒，边想边显示；Antigravity 一句话大约 10~40 秒（Google 那边的速度，会波动），而且是想完才一次性显示。想快就用 DeepSeek。Antigravity 卡片上可以换「模型档位」，聊天用 Flash (Low) 最快，High 会先深度思考，一句话可能要几分钟。

3. **（可选）下载「按意思搜索」模型**
   「设置 → 其他 → 按意思搜索的模型」，点「下载并启用」，再点一次确认。约 2.3GB，只下载一次。
   下载完会自动校验文件，不对就删掉重下，防止下到被篡改的文件。中途断了，再点一次会接着下。
   不下载也能用，只是搜索记忆时只能按关键词找（搜「运动」找不到「晨练」）。

4. **（可选）换头像、换聊天壁纸**
   点左上角的圆圈换头像；在「陪我聊聊」页右上角点「壁纸」换背景，滑块可以调图片的淡化程度。

## 四、每个页面怎么用

| 页面 | 能做什么 |
|---|---|
| **今天** | 今天在电脑前多久、离开多久、记住了几件新事；按时间的记录和各软件用了多久。右上角「现在整理一次」可以马上整理，不用等定时。 |
| **陪我聊聊** | 和 AI 聊天。它说话前会看你的记忆（气泡里会写「读取了你的记忆」）。你说「**记住：……**」它会留便条，下次整理时写进记忆；说「**你记错了，其实是……**」它会记下纠正。聊天记录很长时只显示最近 30 条，**往上滑到顶会自动加载更早的**，不同日期之间有分隔线。 |
| **记忆** | 最上面是「核心画像」（AI 对你的整体了解）；下面是一条条记忆。打勾的是你亲口确认过的；划掉的是后来不再成立的。可以按意思搜索，比如「最近睡得怎么样」。上方的小标签可以**按大分类筛选**（性格、偏好、习惯……）；右上角「**导出 TXT**」把全部记忆按分类导出。 |
| **写入日志** | 每一次对记忆的改动都在这里：谁、什么时候、改了什么。**写错了点「撤销」**，不会真的删除，随时能找回来。按天分组，可按类型筛选（新增、标记失效……），也能「导出 TXT」。 |
| **由谁来回答** | 选聊天和整理记忆分别用哪个 AI，能看到每个 AI 有没有装好。 |
| **设置** | 整理时间、地区、隐私（不记录的软件和关键词、原始记录保留天数）、语言、头像、模型、浏览器扩展、开机自启、使用引导；改完点「保存」。下面还有「记忆库」（见下面）和「关于与更新」。 |

**检查更新**：「设置」最下面「关于与更新 → 检查更新」。只有点这个按钮时才联网。有新版本会弹出更新说明，点「是」后程序会下载、核对校验码，然后自动关闭、安装、再重新打开，记忆和设置都保留。现在发布的都是**测试版**。
也可以手动更新：直接运行新的安装包，覆盖安装就行，**不用先卸载**。

**它还会记什么（0.2.0 起）**
- **正在播放**：后台在放的歌、网页里在看的视频（歌名、歌手、视频标题）。注意：**无痕窗口里放的视频也会被记到**，系统分不出来。
- **最近打开的文件**：只记文件名，不看内容。
- **聊天**：你和 AI 的聊天会在整理时一起整理进记忆。你说的话最可信；AI 的话只用来记「聊过什么」，或者你认同了才算数。「记忆」页每条后面写着来源（你说的 / AI 推测 / 电脑活动 / 一起聊过）。不想让聊天参与，在「设置」里关掉「聊天内容参与整理」：关掉后，还没整理的聊天也不会再交给 AI；以后再打开，只从打开那一刻起算，关着那段时间的聊天不会补进去。聊天时 AI 有时会自己留一张「便条」，提醒整理时记一下某件事，便条后面会附上你刚说的那句话（最多 300 字）。开关打开时，这些便条和聊天一起交给整理记忆的 AI；关掉后，AI 自己想留的便条一律不收，已经留下、还没整理的也会跳过。只有你亲口说「记住……」或「你记错了……」时留的便条，不受这个开关影响，照常整理（会附上你那句话，方便核对）。
- **浏览器扩展**（可选）：「设置 → 浏览器扩展 → 安装浏览器扩展」，确认后选一个文件夹保存，再按提示在 Edge / Chrome 里「加载解压缩的扩展」。它只记 https 网页的网址（去掉参数）、标题和搜索词，不读网页内容，不在无痕窗口运行。保存扩展的文件夹之后不要删。
- **我所在的地区**：「设置 → 整理记忆」。电脑时区和你实际生活的地方不一样时（比如人在英国、电脑是北京时间）在这里选，整理时间、「今天」和记忆里的时间都按它算。

**它还会记什么（0.3.0 起）**
- **电脑睡眠和关机**：合上笔记本、按电源键睡眠、关机的那段时间，会在「今天」的时间线里显示成「电脑睡眠」或「关机」，算作没在用电脑。笔记本、台式机都一样，用的是 Windows 自己的记录，不分品牌。中途短暂亮一下（不到 1 分钟）又睡着的，算一直在睡。
- **我所在的地区**的名字跟着界面语言显示（如「英国 · 伦敦」），可以搜城市或国家。

**聊天时 AI 会上网**（0.3.0 起）：需要最新消息时，AI 会直接上网搜索、看网页，不用每次问你；气泡上会写「上网搜索：……」「打开网页：……」。它不能读写你电脑上的文件、不能运行命令，也不能访问你家里的路由器这类本机 / 局域网地址。

**「记住」要你自己说**：只有你在聊天里亲口说了「记住……」「别忘了……」「你记错了 / 不对，其实是……」，AI 留的便条才会被当成「你亲口确认」；AI 自己觉得该记的，只算普通内容，可信度低一些。

**记忆库（设置 → 记忆库）**（0.3.0 起）
- **位置**：显示记忆库在哪个文件夹，点「打开文件夹」就能看到。文件夹最外层有一份「记忆库说明.md」，是写给 AI 看的。
- **更改位置**：C 盘满了可以搬到别的盘。选一个文件夹，程序会在里面建一个「AlwaysWithYou」文件夹放数据；会先暂停记录、复制并逐个核对，核对无误才删旧的，然后自动重启。
- **导出记忆库**：生成一个压缩包，放在「文档\AlwaysWithYou 导出」。**总是连同全部聊天记录一起导出**，导出前会弹窗提醒。导出的那份里，密码、密钥、手机号、证件号、银行卡这类内容会换成「[已隐藏]」（规则不是万能的，聊到的人名、地址之类会原样保留）。压缩包**没有密码**，请自己保管好；不含 API Key 和原始窗口记录。
  - 到了别的电脑上：解压后把整个文件夹拖给任意 AI 助手（Claude Code、Gemini CLI、Antigravity……），它读了里面的说明就能接着了解你（只能读，不会改）。
  - 装了本软件的话，用下面的「记忆存档」导入，就能接着积累。
- **记忆存档**：点「打开记忆存档」，能看到导入的压缩包和自动备份。点「导入压缩包…」选一个压缩包放进来；选一个点「启用」，程序会**先把当前的记忆自动备份成压缩包放进存档**，再换成那一份，然后自动重启。随时可以再换回去。两份记忆**不会合并**。

**左边栏可以收起**：点边栏右上角的小图标，收起后只剩图标，再点展开。

**切换语言（Language）**：点左下角的地球图标，选「简体中文」或「English」；也可以在「设置 → 其他 → 语言」里选，还能选「跟随系统」（默认就是这个：Windows 是中文就显示中文，否则显示英文）。切换后界面、托盘菜单、通知都会变，AI 整理出来的新记忆也会用这种语言写；聊天时 AI 会用你说话的语言回答。以前已经记下的记忆不会被翻译。

**左下角**能看到「正在记录 / 已暂停记录」和下次整理的时间，「暂停记录」按钮随时可以停。

**关闭窗口不会退出**，它会缩到右下角托盘里继续记录。右键托盘图标会弹出一个手绘风格的小菜单（显示记录状态和下次整理时间），可以：打开主界面、暂停/继续记录、立即整理一次、退出。点别处就会收起。

**导出的 TXT 在哪**：「文档\AlwaysWithYou 导出」文件夹，导出后会自动打开并选中文件。里面是关于你的记忆，分享前注意隐私。

## 五、隐私：它记什么、不记什么、数据在哪

### 会记录
- 最前面窗口的**软件名**和**窗口标题**（例如「Code.exe · memory.py」「msedge.exe · 某个网页标题」）。
- 你离开电脑（5 分钟没动键盘鼠标）、锁屏、电脑睡眠和关机的时间。
- 正在播放的歌和视频、最近打开的文件名；装了浏览器扩展的话还有看过的 https 网页和搜索词。
- 你在「陪我聊聊」里的对话。
- 打开了「设置 → 手机」并配对了手机 AwyRead 的话：手机上每个 App 用了多久、亮屏时间、每小时的步数和心率、每次睡眠（见下面「手机」一节）。

### 不会记录
- 录音、截屏、你按了哪些键、剪贴板、文件内容、通知。
- 「设置 → 隐私」里列出的软件（默认包含常见密码管理器、支付宝等），以及标题里含有你设置的关键词（默认包含「密码」「网银」「银行」「支付宝」「无痕」等）的窗口——这些只记成「隐私窗口」和时长。
- 标题里的密码、账号、手机号、证件号、银行卡、验证码、邮箱、各类密钥等，会在写进硬盘之前被换成「[已隐藏]」。

> **说实话**：自动隐藏靠的是一套规则，不是 AI。它能认出三类东西：
> 1. 有固定格式的：手机号、证件号、银行卡、各种密钥……
> 2. 带标签的：「密码：xxx」「账号：xxx」「QQ 是 xxx」……
> 3. 长得像密码的：夹着 `@ # ! $` 这类符号、又有字母和数字的（如 `Abc@12345`），或者大小写、数字来回乱跳的随机串（如 `x7Kp2Qm9Lw4R`）。
>
> 但**认不出 `zhang123456` 这种看起来和普通名字（比如 `Windows11`）一模一样的简单密码**。偶尔也会把正常的东西误隐藏（比如 YouTube 视频编号），B 站 BV 号、版本号、普通文件名不受影响。
> 所以最稳妥的做法是：把你常用来处理密码的软件加进「不记录的软件」。

### 交给 AI 的是什么
交的是**整理好的电脑活动摘要**（例如「14:00–14:45 在 VS Code 写代码」），不交原始窗口记录。
另外，打开「聊天内容参与整理」时（默认打开），这段时间你和 AI 的**聊天原话**（太长的会截短）也会交给整理记忆的 AI。不想这样，在「设置」里关掉它。用订阅制 AI 时，它只能读你的记忆、留便条、上网搜索和看网页，**不能读写你电脑上的文件、不能执行命令**——它每次想用工具都要先经过本程序同意，本程序按类别放行：读记忆、留便条、上网搜索、看网页可以，其余一律拒绝。上网时搜索词里可能带着你问的问题。

### 数据在哪
全部在你自己的电脑上：默认是 `C:\Users\你的用户名\AppData\Local\AlwaysWithYou\`，搬过家的话以「设置 → 记忆库 → 位置」显示的为准。
- `记忆库说明.md`：写给 AI 看的说明
- `memory.db`：记忆库
- `raw\`：原始记录（默认 30 天后自动删除）
- `summaries\`：每次整理用的摘要
- `chats\`：聊天记录
- `models\`：下载的模型
- `archives\`：记忆存档（导入的压缩包、自动备份）
- `phone\`：手机传数据用的记录（默认没有，配对过手机才有）

### 手机（AwyRead）

手机上装 AwyRead 后，它会读手机的**应用使用时长**和系统健康数据里的**步数、心率、睡眠**（手表数据要先同步到手机，比如欢太健康），
每小时读一次，在**手机和电脑连同一个 Wi-Fi** 时加密传给这台电脑，和电脑活动一起整理成记忆。

1. 电脑上「设置 → 手机」点「打开」。第一次 Windows 可能会问是否允许它访问网络，选「专用网络」并允许。
2. 点「配对新手机」，屏幕上出现 12 位配对码（10 分钟有效）。
3. 手机 AwyRead 拉到「电脑」，填配对码，点「配对」；手机问「附近的设备」权限时选允许。

- 不在家时数据先存在手机上，回家连上 Wi-Fi 再一起传。所以整理出的记忆里可能会提到前几天的事，这是正常的。
- 它**不读**：App 里的内容、聊天、通知、位置。只记 App 名字和时间。「不记录的软件 / 关键词」对手机 App 名也有效（比如名字里有「银行」「支付宝」的 App 只记成「隐私应用」）。
- 交给 AI 的同样只是整理好的「手机活动摘要」。
- 不想用了：电脑上点「关闭」（这台电脑就不再在局域网上等手机），或者在已配对的手机后面点「取消配对」。

## 六、用订阅制 AI 聊天（以 Google Antigravity 为例）

1. 在「由谁来回答」页，找到 Google Antigravity 卡片，点「**一键安装**」。
2. 弹出确认框，上面写着要运行的命令（`irm https://antigravity.google/cli/install.ps1 | iex`，来自 Google 官方）。点「**是**」。
3. 会打开一个 PowerShell 窗口自动安装。装好后它会自动启动一次，按提示用你的 Google 账号登录，登录完关掉这个窗口。
4. 回到本程序，卡片会自动变成「已安装」（每 5 秒检查一次），点「聊天用它」。

> 也可以自己动手：打开 PowerShell 运行上面那条命令，再运行 `agy` 登录。
> Claude Code、Codex 的卡片上也有「一键安装」。Codex 需要先装 Node.js（https://nodejs.org），没装的话窗口里会提示。

## 七、常见问题

**Q：为什么「记忆」页是空的？**
A：刚装好时还没整理过。确认填了 DeepSeek Key，正常用一段时间电脑后，点「今天」页的「现在整理一次」，或等到整理时间。

**Q：AI 记错了怎么办？**
A：两种办法：在聊天里直接告诉它「你记错了，其实是……」；或者到「写入日志」里找到那条，点「撤销」。

**Q：电脑关机/睡眠了，会漏掉整理吗？**
A：不会。开机后程序会把错过的那次补上（只补最近一次）。睡眠和关机的时间会显示在「今天」的时间线里，不算在用电脑。

**Q：换电脑了，记忆怎么带过去？**
A：旧电脑上「设置 → 记忆库 → 导出压缩包」；新电脑装好本软件后「记忆存档 → 导入压缩包…」，再点「启用」。

**Q：想暂时不被记录？**
A：点左下角「暂停记录」，或右键托盘图标选「暂停记录」。

**Q：聊天回复说「出错」？**
A：看看「由谁来回答」页那个 AI 是不是「已安装」；DeepSeek 要检查 Key 和余额；Antigravity 要确认命令行登录过。

**Q：程序打不开或闪退？**
A：详细原因记在 `C:\Users\你的用户名\AppData\Local\AlwaysWithYou\logs\crash.log`，把这个文件发给帮你维护的人（或 AI）。
