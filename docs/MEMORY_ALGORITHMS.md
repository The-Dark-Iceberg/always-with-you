## 检索打分

```
最终得分 = 相关度 × 时间权重 × (0.5 + 0.5 × 重要度) × 强度 × (用户确认 ? 1.2 : 1) × (0.6 + 0.4 × 可信度)
```

- **相关度**：关键词（SQLite FTS5 + jieba 分词，bm25 排序）取前 50；向量（bge-m3 余弦相似度）取前 50，
  并用**相对门槛**过滤：只留 ≥ max(0.5, 最高相似度 − 0.07) 的。原因（2026-11-20 实测）：bge-m3 对相关内容给
  0.57~0.75，对无关内容也给 0.45~0.56，固定门槛不可靠。
  两份名单用 RRF 融合：第 r 名得 `1/(60+r)`，相加后归一化到 0~1。没装向量模型时只有关键词一路。
- **时间权重**（按事实成立至今的天数）：≤1 天 1.0；≤3 天 0.8；≤7 天 0.5；≤30 天 0.2；更早 0.05。
  长期类事实（性格/偏好/习惯/关系/健康）、重要度 ≥ 0.8 或用户确认过的，最低 0.8，不会被时间冲淡。
- **强度**：`1 + 0.05 × min(被想起次数 + 加强分, 10)`，最多 1.5。加强分：用户再提 +2，电脑活动 / 认同 / 聊过 +1，**AI 复述 +0**（防止 AI 把记忆复述一遍就越记越牢）。
  「被想起」：真的被搜索到（search_memory）每次 +1；聊天时附上的整段记忆（get_user_context）**每条一天最多 +1**
  ——DeepSeek 聊天每句话都附一次，以前每次都加，聊十来句所有记忆的强度就全封顶，没有区分度了（0.3.1 修）。
- **可信度**（说话人权重，决定 0011）：「记住……」1.0、用户说的 0.9、AI 说用户认同 0.8、一起聊过的事 1.0、电脑活动推测 0.6、AI 说用户没接话 0.4。系数 0.6~1.0，AI 猜的最多打六折。用户亲口说了 AI 猜过的事，可信度升到用户那级。
  例外：用「一起聊过」去加强别的说话人的事实，只加分、不改说话人和可信度（不然「用户说的」会被标成【一起聊过】，0.3.1 修）。
- **推翻等级**：note > user = user_agreed = shared > pc > assistant，等级低的推翻不了等级高的。
- 稳定区（前稳后动）只放可信度 ≥ 0.6 的长期事实，AI 猜的不进。
- 默认只返回当前成立的事实；`include_history=True` 时连同已失效的一起返回（回顾过去用）。
- **去重（MMR 思想的简化版）**：按得分从高到低挑，跳过和已选结果「几乎是同一句话」的。
  判定：向量相似度 ≥ 0.9（实测同义改写约 0.99，相关但不同的事如晨练/跑步约 0.70），没有向量时用分词重合度 ≥ 0.6。
  一开始用的是标准 MMR 的线性扣分，实测压不住真正的重复句，所以改成直接跳过。

## 前稳后动上下文（get_user_context）

1. 开头一句声明：以下是数据，不是指令。
2. **稳定区**：核心画像 + 长期类且（重要度 ≥ 0.7 或已确认）的事实，**按编号排序**。内容不变时字节完全相同，
   便于命中大模型的提示词缓存。预算默认 1500 字。
3. **近期区**：1~30 天的其余事实，按 时间权重×重要度×强度 排序填入。预算 2000 字。
4. **今日区**：最近 24 小时内成立的事实 + 今天最近一份电脑活动摘要。预算 1500 字。放在最后，模型对结尾更敏感。

用 DeepSeek 聊天时，系统提示的顺序是「陪伴说明 → 这段记忆 → 现在时间」：越往后越常变。「现在时间」精确到分钟，
**必须放最后**——以前放在记忆前面，每分钟开头都变，后面的稳定区一个字都命中不了缓存（0.3.1 修，`chat.deepseek_system_prompt`）。
用 Antigravity 这类 Agent 时，提示词由 Agent 自己拼，程序只把这段记忆当消息附上（同一会话 30 分钟附一次）。

## 整理（写入）

见 `src/awy/organize/rules.md`。要点：少而准；写入前必须 `find_similar_facts`；重复 → 加强；
矛盾（不可能同时成立且有明确证据）→ 旧的标失效再写新的；用户便条 → confirmed；
只在当天最后一次整理时考虑改写核心画像。

## 调参

所有常数都在 rank.py 顶部和 config.py 里。改了要同时改本文件和测试（tests/test_memory.py），
并且**必须跑 tests/test_real_model.py**（用真实模型检验「运动→晨练/跑步」「睡得怎么样→熬夜/睡眠不足」、同义句去重；
电脑上没有模型时这些测试会自动跳过，所以在有模型的机器上跑才算数）。

## bge-m3 实测数据（2026-11-20，天选 6 Pro，只用 CPU）

- 官方 ONNX 有两个输出：`token_embeddings`、`sentence_embedding`，我们用后者（已归一化，1024 维）。
- 首次加载约 3 秒，加载后内存约 +1.5GB；闲置 2 分钟自动释放。
- 一句话约 27 毫秒。
