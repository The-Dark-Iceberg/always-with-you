## 0.3.0

**第一次打开 / First launch**
- 先看风险确认，点「我了解风险并接受使用」之后才开始记录；然后是 7 步引导（可以跳过，设置里能重新打开）。
  A risk notice comes first; nothing is recorded until you accept. Then a 7-step setup guide (skippable, reopen from Settings).
- 设置不自动保存：改了没保存时「保存」按钮一直高亮，想离开会提醒。
  Settings are never saved silently: the Save button glows while there are unsaved changes, and you're reminded before leaving.

**记忆库 / Memory library**
- 设置里能看到记忆库在哪、打开文件夹、搬到别的盘。文件夹里有一份写给 AI 看的说明。
  See where the memory library lives, open it, or move it to another drive. A guide for AI agents sits in the folder.
- 导出记忆库压缩包（可带聊天记录）：解压后拖给任意 AI 助手就能接着了解你。
  Export the library as a zip (chat history optional): unzip and hand the folder to any AI agent.
- 记忆存档：导入压缩包、一键启用，启用前自动备份当前的记忆。
  Memory archives: import zips and switch with one click; your current memories are backed up first.

**更懂你 / Knows you better**
- 记录电脑睡眠和关机（笔记本、台式机都一样），算作没在用电脑。
  Computer sleep and shutdown are recorded (laptops and desktops alike) and count as time away.
- 聊天时 AI 可以上网搜索最新消息；仍然不能读写你的文件、不能运行命令。
  The AI can search the web while chatting; it still can't touch your files or run commands.
- 「记住」只有你亲口说才算数。
  "Remember" notes only count when you said it yourself.

**其他 / Other**
- 「我所在的地区」名字跟着界面语言显示，可以搜索。
  Region names follow the interface language and can be searched.
- 全屏时界面铺满。
  The window content now fills the screen when maximized.
