## 0.4.1

**手机 / Phone**
- 配对码旁边多了「复制配对码」按钮。
  A "Copy pairing code" button next to the pairing code.
- 「这台电脑的地址」只显示真实的 Wi-Fi / 有线网卡；VPN、组网工具、虚拟机的网卡不再显示，从那边来的请求也一律不收。
  "This computer's address" only lists real Wi-Fi / wired adapters; VPN, virtual network and virtual machine adapters are hidden and requests coming through them are refused.
- 说明了公司、学校这类 Wi-Fi 常常不让设备互相连接时该怎么办（用家里的 Wi-Fi，或者让手机连电脑的移动热点）。
  Explains what to do when workplace or school Wi-Fi stops devices from reaching each other (use home Wi-Fi, or connect the phone to this computer's Mobile hotspot).
