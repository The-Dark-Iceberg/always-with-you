Always With You · 记录助手（浏览器扩展）
=========================================

这个扩展只告诉本机的「一个时刻陪着你的AI」你正在看哪个网页：
- 只记 https 网页的网址（去掉 ? 后面的全部参数）、域名、标题，以及搜索引擎里的搜索词。
- http（不加密）网页、浏览器自己的页面一律不记。
- 不读网页内容、不读输入框和密码、不读 Cookie。
- 不在无痕 / InPrivate 窗口里运行。
- 数据只发给本机程序（127.0.0.1），不上传任何地方。

安装（Edge）：
1. 地址栏输入 edge://extensions 回车
2. 打开左边的「开发人员模式」
3. 点「加载解压缩的扩展」，选这个文件夹
安装（Chrome）：
1. 地址栏输入 chrome://extensions 回车
2. 打开右上角的「开发者模式」
3. 点「加载已解压的扩展程序」，选这个文件夹

注意：这个文件夹装好后不要删除，删了浏览器里的扩展就没了。
Edge 启动时如果提示「关闭开发人员模式扩展」，点忽略即可。


Always With You · Browser helper
--------------------------------
Tells the local Always With You app which web page you're on: https URL (all query parameters
removed), domain, title, and search terms on search engines. Never reads page content, form fields
or cookies; doesn't run in incognito; sends data only to 127.0.0.1.

Install: open edge://extensions or chrome://extensions, turn on Developer mode,
click "Load unpacked" and choose this folder. Don't delete the folder afterwards.
