# 项目目标

## 一句话

做一个**真正懂用户**的 AI：在用户自己的电脑上长期、安静地积累关于他的记忆，
让他想聊天时，AI 一开口就知道他是谁、最近怎么样、今天在做什么。

## 起源

受 B 站 UP 主 Xehuri 的开源项目 Kinship（github.com/Xehuri/kinship）启发。我们不复用它的代码，
而是做一个更小、更安全、以「记忆」为核心的版本。讨论过程中参考了 Graphiti、Mem0、Generative Agents、
MemoryBank、MemoryOS 等记忆项目的算法（见 MEMORY_ALGORITHMS.md）。

## 要做的

- **Windows 桌面程序**：双击即用，托盘常驻，有正常的安装和卸载程序。不用网页界面。
- **电脑端采集**：前台窗口与标题、离开/回来。（以后：正在播放的媒体、浏览器历史）
- **隐私过滤**：黑名单 + 打码，先过滤再落盘。
- **记忆库**：本地 SQLite 单文件，事实带时间（何时成立、何时失效），可撤销。
- **定时整理**：每天几次，把摘要交给 AI（DeepSeek API 或订阅制 Agent）按固定规则写进记忆库。
- **读写分开的 MCP**：聊天的 AI 只能读和留便条；只有整理任务能写。
- **工作和陪伴分开**：只有「陪伴文件夹」接了记忆库，工作时完全不加载记忆，不多花额度。
- **以后**：手机端「搬运工」App（App 使用时长、Health Connect 心率/步数/睡眠、可选定位），通过 Tailscale 传给电脑。

## 明确不做的（以及原因）

| 不做 | 原因 |
|---|---|
| 无障碍权限 | 能读到屏幕上的一切（包括聊天和密码），一旦被「下毒」后果严重，也是诈骗软件常用的手段 |
| 环境录音 | 耗电、录到别人、隐私风险大；用户已决定去掉 |
| 读取通知内容 | 能看到验证码和聊天预览 |
| 键盘记录、截屏 | 同上 |
| 网页界面 | 用户和大多数人更喜欢桌面客户端 |
| 云端服务器 | 数据只留在用户自己的电脑上 |
| 把订阅账号接到第三方程序 | 违反各家条款，可能封号；订阅制 Agent 只能通过它自己的官方客户端调用我们的 MCP |
| 学习时长/学习程度模块 | 暂时剔除：手机端读不到学习内容。以后可从电脑端（窗口标题能看到文件名、网页标题）重新开始 |

## 成功的标准

1. 用户每天开机后它安静地运行，不需要照顾。
2. 用户在陪伴文件夹里和 AI 聊天时，AI 能自然地提到他最近的状态，而且说得对。
3. 说错了，用户纠正一次就能改过来。
4. 用户随时能看到它记了什么、改了什么，并且能撤销。
