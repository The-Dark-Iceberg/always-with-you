## 0.4.3 · AwyRead 0.3.2

- 「检查更新」改成看本仓库的 Releases（以前指向一个没建成的发布仓库，查不到更新）。电脑端和手机端都能用了；已安装的旧设置会自动换过来。
  "Check for updates" now looks at this repository's Releases (it used to point at a releases repo that was never created). Works on both the computer and the phone; existing settings switch over automatically.
- 手机端按安装包文件名 `AwyRead-<版本>.apk` 判断有没有新版。
  The phone app now reads its version from the file name `AwyRead-<version>.apk`.

> 从 0.4.2 / 0.3.1 升级需要手动下载这一版；之后的版本可以在程序里直接检查更新。
> Upgrading from 0.4.2 / 0.3.1 needs a manual download this once; later versions can be found from inside the apps.
